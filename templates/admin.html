🏆 Start Fresh Tournament

Factory Wipe: Delete all registered players, delete teams & stop live auction
⚠️ FULL FACTORY RESET
💥 What happens when you Start Fresh Tournament?
  • 🗑️ Delete All Registered Players: Clears all registered players from the project database (registrations.json is wiped clean).
  • 🛡️ Delete All Teams: Removes all teams, squad rosters, team passcodes, and retentions.
  • 🛑 Stop Live Auction: Live auction broadcast is stopped; active bidding, unsold pools, and history are wiped.
  • ✨ 100% Brand New Season: Provides a clean slate to register new players and set up new teams for the upcoming tournament.
